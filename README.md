<h1 align="center">苍穹外卖</h1>

<h3 align="center">基于 SpringBoot + Vue 前后端分离的 企业级外卖点餐系统</h3>

## 背景介绍

苍穹外卖项目是随着互联网及移动支付技术的普及及发展，运用现代软件工程技术对传统餐饮行业进行数字化改造升级。从B端商家角度来看，旨在提升传统餐饮店的运营、出餐效率，通过订单数据的采集和分析不断优化运营方案，降低人工和运营成本；针对C端用户的点餐体验，将传统的纸质菜单点餐、人工收银流程替换成微信小程序扫码点餐、线上支付的快捷方式，最大程度提升用户的点餐和购物体验。

## 业务介绍

随着餐饮平台方运营的店铺数量及订单数量越来越多，为了降低成本、加快运营效率，平台方将系统做了切分。其中主要包含两个端：**管理端**主要面向商家及运营人员，主要用于管理员工、菜品分类、菜品及套餐上下架、订单处理以及数据统计，帮助商家提高日常运营效率，减少漏单错单；**用户端**主要面向C端用户，基于微信小程序开发，提供微信登录、浏览菜单、加入购物车、微信支付及历史订单查询等功能，缩短用户点餐流程。
